# CRM & Data Automation Toolkit

This repository contains Python-based tools designed to automate data enrichment, entity matching, and workflow processes used in a consulting and business operations environment.

These tools were developed to support CRM system improvements, enhance data quality, and enable more effective decision-making through automation and scalable data pipelines.

---

## 🚀 Overview

The scripts in this repository focus on solving common data challenges in operational and consulting settings, including:

- Data enrichment from external sources
- Leadership and contact tracking
- Fuzzy matching for entity resolution
- Multi-source data merging and cleaning
- Automation of repetitive data workflows

---

## 🧠 Use Cases

These tools were built to support real-world business needs such as:

- Improving executive contact coverage within CRM systems  
- Tracking leadership changes across organizations  
- Cleaning and merging large datasets from multiple sources  
- Supporting targeted outreach and business development initiatives  
- Reducing manual data processing and increasing operational efficiency  

---

## 🛠 Tech Stack

- Python  
- Pandas  
- RapidFuzz (for fuzzy matching)  
- AWS (EC2, S3)  
- Excel / CSV data processing  

---

## ⚙️ Key Capabilities

### 1. Data Enrichment
Enhances datasets by integrating external data sources to improve completeness and usability.

### 2. Fuzzy Matching
Uses similarity scoring to match records with inconsistent naming (e.g., executive names across systems).

### 3. Data Cleaning & Transformation
Standardizes and prepares data for downstream analysis and reporting.

### 4. Workflow Automation
Automates repetitive data tasks, reducing manual effort and improving consistency.
